# Wauz Kart Website

Express-Website fuer Wauz Kart. Vercel startet das Backend ueber `api/index.js`.

## Lokal starten

```bash
npm install
npm run dev
```

Danach ist die Website unter `http://localhost:3000` erreichbar.

## Routen

- `/` - Website
- `/garage` - Charaktere und Autos
- `/wiki` - kleine Wauz-Kart-Wiki
- `/api/health` - Backend-Check
- `/api/wiki` - Daten fuer Charaktere, Autos, Strecken, Items und Modi
- `/download/wauzkart` - Download fuer `assets/wauzkart.exe`

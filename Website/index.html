Installation

Die richtige Datei fuer dein System

Windows

Auto-Installer starten

Lade install-wauzkart-windows.cmd. Er installiert Wauz Kart nach LocalAppData, erstellt Verknuepfungen und aktualisiert beim erneuten Start automatisch.

Linux

Einfacher Installer

Lade install-wauzkart-linux.sh herunter und starte ihn. Er holt die aktuelle DEB-Datei und installiert die benoetigten Pakete automatisch. Danach Wauz Kart ohne sudo starten.

Linux

DEB installieren

Lade wauzkart-linux.deb fuer Debian, Ubuntu oder Linux Mint, wenn dein System AppImages nicht direkt startet. Installieren darf sudo nutzen, Spielen nicht.

Linux

AppImage direkt starten

Lade wauzkart-linux.AppImage, setze Ausfuehrbar-Rechte und starte die Datei direkt, wenn dein Desktop AppImages unterstuetzt.

macOS

Auto-Installer starten

Lade install-wauzkart-macos.sh. Er holt das aktuelle DMG und ersetzt die installierte App automatisch.

Hilfe

Haeufige Fragen

Wo werden Spielstaende gespeichert?

Scores, Rennen, Level und Abzeichen liegen lokal in Roaming/Wauzkart, nicht im Assets-Ordner.

Kann man offline spielen?

Ja. Das Spiel ist lokal spielbar. Die Website braucht nur Internet fuer Download und GitHub-Release.

Welche Datei soll ich laden?

Am einfachsten sind die Auto-Installer fuer Windows, Linux und macOS. EXE, DEB, AppImage und DMG bleiben als direkte Alternativen verfuegbar.

Wie merke ich neue Updates?

Wauz Kart prueft beim Start kurz GitHub. Wenn eine neue Version da ist, zeigt das Spiel den passenden Installer fuer dein System an.

Wie wechseln die Kameras?

Mit F3 wechselst du zwischen Verfolgerkamera, Innenperspektive und Top-Down-Ansicht.

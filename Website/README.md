# Wauz Kart Website

Statische Website fuer Wauz Kart. Vercel liefert nur HTML, CSS, JS, Bilder und JSON aus.

## Lokal starten

```bash
py -m http.server 3000
```

Danach ist die Website unter `http://localhost:3000` erreichbar.

## Routen

- `/` - Website
- `/garage` - Charaktere und Autos
- `/wiki` - kleine Wauz-Kart-Wiki
- `/data/wiki-data.json` - Daten fuer Charaktere, Autos, Strecken, Items und Modi

Die Download-Buttons zeigen direkt auf die GitHub-Release-Dateien: Windows EXE, Linux Auto-Installer, Linux AppImage, Linux DEB und macOS DMG.

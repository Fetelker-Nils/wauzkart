Hilfe

Update- und Installationshilfe

Schnelle Hilfe, wenn Download, Installation, Audio, OpenGL oder LAN nicht direkt funktionieren.

Update Windows Linux macOS LAN Daten

Update

Wenn das automatische Update fehlschlaegt

Oeffne die Download-Sektion, lade den passenden Installer erneut und starte ihn manuell. Deine Fortschrittsdaten bleiben im Benutzerprofil gespeichert.

Wenn GitHub kurz limitiert oder langsam ist, warte ein paar Minuten und starte Wauz Kart erneut. Neue Versionen laden einen tag-genauen Installer der gefundenen Release.

Windows

Windows-Installer

Lade install-wauzkart-windows.exe. Wenn Windows warnt, bestaetige nur Installer, die von der offiziellen GitHub-Release-Seite oder dieser Website kommen.

Falls ein Update nicht kopieren kann, schliesse alle Wauz-Kart-Fenster und starte den Installer erneut.

Linux

Linux-SH-Installer

Lade install-wauzkart-linux.sh, mache die Datei ausfuehrbar und starte sie. Der Installer darf sudo fuer Systempakete nutzen, das Spiel selbst soll danach ohne sudo gestartet werden.

Bei Audio-Problemen pruefe PulseAudio/PipeWire und GStreamer-Pakete. Bei OpenGL-Problemen pruefe Grafiktreiber und EGL/GLX-Pakete.

macOS

macOS-DMG

Lade wauzkart-macos.dmg, oeffne die Datei und installiere die App. Bei Sicherheitswarnungen oeffne sie ueber Systemeinstellungen oder Rechtsklick/Oeffnen.

LAN

LAN-Verbindung

Host und Client muessen im selben Netzwerk sein. Wenn automatische Suche nichts findet, gib die Host-IP manuell ein und erlaube Wauz Kart in der Firewall.

Ports: TCP 27711 fuer Rennen und UDP 27712 fuer Host-Suche.

Daten

Spielstaende

Scores, Abzeichen, Rennen und AGB-Zustimmung liegen im Benutzerprofil, nicht im Assets-Ordner. Unter Windows ist das normalerweise AppData/Roaming/Wauzkart.
